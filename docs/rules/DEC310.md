# DEC310 model-overlapping-questions

Jev reads two questions in one request as asking for the same judgment.

On by default, as `info`. Asks the model. It runs only under an **Ask** command in the editor or `--ask` on the command line, with your key, and never while linting.

## What Jev is asked

This one is asked about a whole request, not one question: every pair of questions, or the state written in the file.

It is reported when the model puts the probability of yes at or above its cutoff: 0.12 on `jev-1.14.0`, 0.01 on `gpt-6-luna` and 0.03 on `d1`. Each cutoff was fit on examples the project wrote, so treat a finding as an argument with a number attached, not a verdict. How it holds up on each model and platform it was run on is in [the cutoffs page](../cutoffs.md).

## Fixing it

There is no automatic fix. The change is yours to make.

## Silencing it

In code, on the line above:

```ts
// decisionlint-disable-next-line DEC310
```

In JSON, which has no comments, by question id in `decisionlint.json`:

```json
{ "ignore": ["DEC310:your-question-id"] }
```
