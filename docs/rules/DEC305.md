# DEC305 model-label-mismatch

Jev reads an option as named for one thing and described as another.

On by default, as `warning`. Asks the model. It runs only under an **Ask** command in the editor or `--ask` on the command line, with your key, and never while linting.

## What Jev is asked

> In `question.criteria`, does any option have a name that says one thing while its description says another?

It is reported when the model puts the probability of yes at or above its cutoff: 0.66 on `jev-1.14.0`, 0.34 on `gpt-6-luna` and 0.37 on `d1`. Each cutoff was fit on examples the project wrote, so treat a finding as an argument with a number attached, not a verdict. How it holds up on each model and platform it was run on is in [the cutoffs page](../cutoffs.md).

## Fixing it

There is no automatic fix. The change is yours to make.

## Silencing it

In code, on the line above:

```ts
// decisionlint-disable-next-line DEC305
```

In JSON, which has no comments, by question id in `decisionlint.json`:

```json
{ "ignore": ["DEC305:your-question-id"] }
```
