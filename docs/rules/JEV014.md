# JEV014 question-limit

A request has more questions than the platform it goes to takes in one call. The platform rejects it.

On by default, as `error`. An exact rule. It reads the shape of the question and does not guess.

## Example

It takes a `target` that publishes a limit, such as `litellm`, and 129 questions to trigger, which is too long to show here.

## Fixing it

There is no automatic fix. The change is yours to make.

## Silencing it

In code, on the line above:

```ts
// jevlint-le-disable-next-line JEV014
```

In JSON, which has no comments, by question id in `jevlint-le.json`:

```json
{ "ignore": ["JEV014:your-question-id"] }
```
