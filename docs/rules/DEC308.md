# DEC308 model-unordered-levels

Jev reads a Score's levels as unordered categories, which a Choice would pick from.

On by default, as `info`. Asks the model. It runs only under an **Ask** command in the editor or `--ask` on the command line, with your key, and never while linting.

## What Jev is asked

> Are the levels in `question.criteria` different kinds of thing, with no order from less to more between them?

It is reported when the model puts the probability of yes at or above its cutoff: 0.5 on `jev-1.14.0`, 0.88 on `gpt-6-luna` and 0.89 on `d1`. Each cutoff was fit on examples the project wrote, so treat a finding as an argument with a number attached, not a verdict. How it holds up on each model and platform it was run on is in [the cutoffs page](../cutoffs.md).

## Fixing it

There is no automatic fix. The change is yours to make.

## Silencing it

In code, on the line above:

```ts
// decisionlint-disable-next-line DEC308
```

In JSON, which has no comments, by question id in `decisionlint.json`:

```json
{ "ignore": ["DEC308:your-question-id"] }
```
