# DEC304 model-overlapping-levels

Jev reads two levels of a Score as the same situation.

On by default, as `warning`. Asks the model. It runs only under an **Ask** command in the editor or `--ask` on the command line, with your key, and never while linting.

## What Jev is asked

> Do two of the levels in `question.criteria` describe the same situation in different words?

It is reported when the model puts the probability of yes at or above its cutoff: 0.6 on `jev-1.13.0` and 0.15 on `d1`. It is not asked of `gpt-6-luna`, where no cutoff told the examples with the defect from the examples without. Each cutoff was fit on examples the project wrote, so treat a finding as an argument with a number attached, not a verdict. How it holds up on each model and platform it was run on is in [the cutoffs page](../cutoffs.md).

## Fixing it

There is no automatic fix. The change is yours to make.

## Silencing it

In code, on the line above:

```ts
// decisionlint-disable-next-line DEC304
```

In JSON, which has no comments, by question id in `decisionlint.json`:

```json
{ "ignore": ["DEC304:your-question-id"] }
```
