# JEV013 newer-model

`model` names a Jev version newer than the one these rules were measured on, so a finding may cost nothing there and a weakness new to it is not looked for.

On by default, as `info`. An exact rule. It reads the shape of the question and does not guess.

## Flagged

```json
{
  "model": "jev-99.0.0",
  "questions": {
    "q": {
      "type": "noul",
      "instructions": "Does the customer ask for their money back?"
    }
  }
}
```

> 'jev-99.0.0' is newer than jev-1.13.0, the version these rules were measured on. A finding may cost no answers on it, and a weakness new to it is not looked for. A later JevLint-LE may have measured it.

## Not flagged

```json
{
  "model": "jev-1.13.0",
  "questions": {
    "q": {
      "type": "noul",
      "instructions": "Does the customer ask for their money back?"
    }
  }
}
```

## Fixing it

There is no automatic fix. The change is yours to make.

## Silencing it

In code, on the line above:

```ts
// jevlint-le-disable-next-line JEV013
```

In JSON, which has no comments, by question id in `jevlint-le.json`:

```json
{ "ignore": ["JEV013:your-question-id"] }
```
