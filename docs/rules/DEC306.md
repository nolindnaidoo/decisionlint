# DEC306 model-criteria-off-topic

Jev reads the criteria as deciding something the instructions do not ask.

On by default, as `info`. Asks the model. It runs only under an **Ask** command in the editor or `--ask` on the command line, with your key, and never while linting.

## What Jev is asked

> Do the criteria in `question.criteria` decide something other than what `question.instructions` asks?

It is reported when the model puts the probability of yes at or above its cutoff: 0.52 on `jev-1.14.0` and 0.36 on `d1`. It is not asked of `gpt-6-luna`, where no cutoff told the examples with the defect from the examples without. Each cutoff was fit on examples the project wrote, so treat a finding as an argument with a number attached, not a verdict. How it holds up on each model and platform it was run on is in [the cutoffs page](../cutoffs.md).

## Fixing it

There is no automatic fix. The change is yours to make.

## Silencing it

In code, on the line above:

```ts
// decisionlint-disable-next-line DEC306
```

In JSON, which has no comments, by question id in `decisionlint.json`:

```json
{ "ignore": ["DEC306:your-question-id"] }
```
