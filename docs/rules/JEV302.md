# JEV302 jev-undefined-boundary

Jev reads a Noul as turning on a matter of degree with no stated line.

On by default, as `info`. Asks the model. It runs only under an **Ask** command in the editor or `--ask` on the command line, with your key, and never while linting.

## What Jev is asked

> Does `question` turn on a matter of degree, such as how large, how often, how good or how soon, without saying where yes ends and no begins?

It is reported when Jev puts the probability of yes at 0.7 or more. That cutoff was set from a small number of examples on `jev-1.13.0`, so treat a finding as an argument with a number attached, not a verdict.

## Fixing it

There is no automatic fix. The change is yours to make.

## Silencing it

In code, on the line above:

```ts
// decisionlint-disable-next-line JEV302
```

In JSON, which has no comments, by question id in `decisionlint.json`:

```json
{ "ignore": ["JEV302:your-question-id"] }
```
