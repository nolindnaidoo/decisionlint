# DEC311 model-answer-not-in-state

Jev reads the state written in the file as not holding what the question asks about.

On by default, as `info`. Asks the model. It runs only under an **Ask** command in the editor or `--ask` on the command line, with your key, and never while linting.

## What Jev is asked

> Is what `question.instructions` asks about missing from `state`?

It is reported when Jev puts the probability of yes at 0.85 or more. That cutoff was set from a small number of examples on `jev-1.13.0`, so treat a finding as an argument with a number attached, not a verdict. How it holds up on each model and platform it was run on is in [the cutoffs page](../cutoffs.md).

## Fixing it

There is no automatic fix. The change is yours to make.

## Silencing it

In code, on the line above:

```ts
// decisionlint-disable-next-line DEC311
```

In JSON, which has no comments, by question id in `decisionlint.json`:

```json
{ "ignore": ["DEC311:your-question-id"] }
```
