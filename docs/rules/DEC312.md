# DEC312 model-orders-in-state

Jev reads part of the state written in the file as giving orders to its reader.

On by default, as `info`. Asks the model. It runs only under an **Ask** command in the editor or `--ask` on the command line, with your key, and never while linting.

## What Jev is asked

This one is asked about a whole request, not one question: every pair of questions, or the state written in the file.

It is reported when the model puts the probability of yes at or above its cutoff: 0.93 on `jev-1.14.0` and 0.97 on `gpt-6-luna`. It is not asked of `d1`, where no cutoff told the examples with the defect from the examples without. Each cutoff was fit on examples the project wrote, so treat a finding as an argument with a number attached, not a verdict. How it holds up on each model and platform it was run on is in [the cutoffs page](../cutoffs.md).

## Fixing it

There is no automatic fix. The change is yours to make.

## Silencing it

In code, on the line above:

```ts
// decisionlint-disable-next-line DEC312
```

In JSON, which has no comments, by question id in `decisionlint.json`:

```json
{ "ignore": ["DEC312:your-question-id"] }
```
