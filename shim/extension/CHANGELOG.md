# Changelog

## 0.9.0 — 2026-10-14

**JevLint-LE is now DecisionLint.** This is the last version under the old
name, and it lints nothing. On startup it offers to install
`nolindnaidoo.decisionlint`, which lints the questions sent to every
decision-model platform, and to remove itself. 0.8.1 was the last version
that linted on its own; its changelog continues under DecisionLint at
https://github.com/nolindnaidoo/decisionlint/blob/main/CHANGELOG.md.
